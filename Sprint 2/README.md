# Resumo da sprint 2
Durante esta sprint, nossa jornada educacional foi dividida em dois cursos fundamentais: SQL e Big Data.
Estas são ferramentas cruciais no mundo da tecnologia, e foi minha primeira exposição a elas.

## SQL
No curso de SQL, exploramos uma ampla gama de comandos, desde os básicos até os mais avançados.

 * Fundamentos Essenciais:
Aprendemos a estruturação de consultas com comandos como SELECT, FROM, e WHERE, permitindo-nos recuperar dados específicos de bancos de dados.

* Operadores Avançados:
Expandimos nossos conhecimentos ao usar operadores mais complexos, como JOIN, INNER JOIN, e LEFT JOIN, 
permitindo-nos combinar dados de diferentes tabelas de maneira eficaz.

* Funcionalidades Avançadas:
Com o uso de funções agregadas como SUM, COUNT, e AVG, proporcionando-nos a capacidade de realizar análises estatísticas em grandes conjuntos de dados.

## :cloud: Big Data

Durante o curso de Big Data, mergulhamos em um universo de conhecimento abrangente.
Onde foi abordado fundamentos dos "4 Vs" do Big Data: Volume, Velocidade, Variedade e Veracidade.

També foi abordado sobre o armazenamento de Big Data, abordando estratégias e ferramentas para gerenciar essas grandes quantidades de informações. 
Foi pontuado bancos de dados não relacionais e NoSQL, que se destacam em lidar com a diversidade de fontes e tipos de dados.

O curso também nos levou ao universo do Data Warehouse (DW) e Data Lakes, plataformas fundamentais para armazenar e analisar dados de forma estruturada e não estruturada. Exploramos conceitos como Data Store e Apache Hadoop, que são pilares no processamento e gerenciamento eficiente do Big Data.

Além disso, foi visto a abordagem inovadora de Cloud Computing, que se tornou um pilar essencial para lidar com grandes volumes de dados de forma escalável e econômica.
