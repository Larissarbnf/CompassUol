Na quarta Sprint, o primeiro curso foi voltado a Python com programação funcional, isso significa que pode escrever código em Python de maneira funcional, 
aproveitando conceitos como funções de primeira classe, funções de ordem superior, map, filter, reduce, entre outros.

### Funções de Primeira Classe:

Em Python, as funções são tratadas como cidadãos de primeira classe, o que significa que elas podem ser passadas como argumentos para outras funções,
retornadas como valores de outras funções e armazenadas em variáveis.

### Funções de Ordem Superior:

Refere à capacidade de uma função de aceitar outras funções como argumentos ou retorná-las como resultado.

### Map, Filter e Reduce:
Estas são funções incorporadas que são muito utilizadas em programação funcional.
* map: Aplica uma função a todos os itens em uma entrada.
* filter: Filtra os itens em uma sequência baseados em uma condição.
* reduce: Aplica uma função cumulativa a todos os itens de uma sequência.

Nessa secção também foi abordado a função lambda que é uma maneira de definir funções pequenas e 
anônimas sem a necessidade de utilizar a palavra-chave "def"

Também foi falado sobre Generators (ou geradores) que são uma maneira eficiente de criar sequências de dados sem a necessidade de
armazenar todos os elementos na memória ao mesmo tempo. 

## <img src="https://logos-world.net/wp-content/uploads/2021/02/Docker-Logo.png" width="75">  Docker para Desenvolvedores

O curso abrangente sobre Docker proporcionou aos desenvolvedores um mergulho profundo no mundo da contêinerização,
cobrindo desde os conceitos fundamentais até tópicos avançados como orquestração com Kubernetes. 

Foi abordado nessa seção a criação de imagens que é uma das maiores vantagens do Docker é a capacidade de criar imagens personalizadas a partir de 
contêineres. Esse processo é fundamental para a customização e distribuição eficiente de ambientes de desenvolvimento ou aplicações específicas. 

Também posso citar que foi introduzido e explicado sobre volumes no Docker, onde volumes são uma maneira essencial de gerenciar e persistir dados de forma 
eficiente entre contêineres. Eles proporcionam uma solução flexível para armazenar informações que precisam
ser mantidas mesmo após a finalização ou remoção de um contêiner. 

Alguns pontos que também foram pontuados e debatidos nessa seção:

* Conectando Contêineres a Redes no Docker- Ao trabalhar com Docker, é crucial entender como conectar contêineres a redes para facilitar a
comunicação entre diferentes serviços.

* YAML - Que é uma linguagem de marcação de dados de formato humano, frequentemente utilizada para configuração,
serialização de dados e troca de informações em ambientes onde a legibilidade humana é uma prioridade.
Uma das maiores vantagens do YAML é sua sintaxe simples e intuitiva.
Utiliza espaçamento e indentação para definir a estrutura dos dados, o que o torna muito legível e fácil de entender.

* Docker Compose - O Docker Compose é uma ferramenta que facilita a definição, configuração e execução de aplicações compostas por vários contêineres Docker.
Ele permite que você descreva a configuração de sua aplicação em um arquivo YAML e depois a execute com um único comando.

* Docker Swarm- É uma ferramenta de orquestração nativa do Docker que permite gerenciar e orquestrar clusters de contêineres. 
Ele simplifica a execução de aplicações distribuídas, dividindo-as em serviços e distribuindo esses serviços entre os nós do cluster.
