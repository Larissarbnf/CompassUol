## Resumo da sprint 1
Nesta sprint, o conteúdo foi dividido em dois cursos: Linux e Git/GitHub. Foi nossa primeira experiência com essas ferramentas essenciais.

## <img src="https://git-scm.com/images/logos/downloads/Git-Icon-1788C.png" width="25">  Git e GitHub

No curso foram vistos comandos essenciais para controle de versões com Git, como git init, git add, e git commit, que são fundamentais para
acompanhar mudanças em projetos. repositório remoto, e git push para enviar minhas alterações para o servidor.

Além disso, também foi abordado comandos mais simples, como git pull para obter atualizações do repositório remoto,
e git push para enviar minhas alterações para o servidor.
 
No entanto, o curso também mergulhou em comandos mais avançados, permitindo um controle mais preciso do código,
como a criação de branches (git branch) para desenvolvefuncionalidades separadamente e fusões (git merge) para incorporar essas mudanças ao código principal.
Entre outros comandos abordado durante esse curso.

## <img src="https://www.pngall.com/wp-content/uploads/5/Linux-Logo-PNG-File.png" width="25"> Linux 

Ao longo do curso de Linux, fui guiado por um mergulho profundo nesse sistema operacional de código aberto. Desde a criação da minha primeira máquina virtual,
aprendi os fundamentos e funcionalidades vitais para qualquer administrador de sistemas.

Ao explorar a linha de comando, percebi a potência da interface do Linux. Comandos como ls, cd, mkdir, e cp tornaram-se aliados na navegação e manipulação de arquivos.
